# 오명석의 To-do

`example.png`의 어두운 배경과 노란색 강조 디자인을 참고하여 만든 할 일 관리 웹페이지입니다. HTML로 화면의 구조를 만들고, CSS로 디자인을 적용하며, JavaScript로 할 일 생성·조회·수정·완료 표시·삭제 기능을 구현했습니다. 별도의 프레임워크나 패키지 설치 없이 실행할 수 있습니다.

## 주요 파일 구성

```text
현재 폴더/
├── index.html       # 페이지 구조 및 CSS·JavaScript 연결
├── css/
│   └── style.css    # 색상, 배치, 입력창과 목록의 디자인
├── js/
│   └── todo.js      # 할 일 데이터 관리 및 사용자 이벤트 처리
├── example.png     # 디자인 참고용 견본 이미지
└── readme.md       # 구현 및 사용 안내
```

## 1. 구현 방법

### 1-1. HTML: 페이지의 구성요소 만들기

`index.html`은 화면의 기본 구조와 사용자가 조작할 입력 요소를 정의합니다.

| 구성요소 | 구현 내용과 역할 |
| --- | --- |
| `header.site-header` | 노란색 원, 번호 `03`, 페이지 이름을 표시합니다. |
| `main.page-shell` | 할 일 앱을 감싸는 본문 영역입니다. |
| `section.todo-app` | 소개 문구, 제목, 입력 폼, 목록, 안내 문구를 묶습니다. |
| `form#todo-form` | 입력창과 **추가** 버튼을 묶어 클릭이나 Enter로 제출할 수 있게 합니다. |
| `input#todo-input` | 새 할 일을 입력합니다. `required`로 빈 입력을 제한하고 `maxlength="100"`으로 입력 길이를 제한합니다. |
| `ul#todo-list` | JavaScript가 생성한 할 일 항목(`li`)을 표시하는 공간입니다. |
| `p#empty-message` | 항목이 없을 때 “등록된 할 일이 없습니다.”를 표시합니다. |

외부 파일은 다음과 같이 연결합니다.

```html
<link rel="stylesheet" href="css/style.css">
<script src="js/todo.js" defer></script>
```

`defer`는 HTML 문서의 파싱이 끝난 뒤 스크립트를 실행하도록 하여 JavaScript가 화면 요소를 찾을 수 있게 합니다. `viewport` 메타 태그는 모바일 화면의 너비에 맞춰 페이지를 표시하도록 설정합니다.

접근성을 위해 입력창에 연결된 `label`을 제공하고, `.sr-only`로 화면에서만 숨깁니다. `aria-labelledby="page-title"`은 영역과 제목을 연결하며, 목록의 `aria-live="polite"`는 화면 읽기 프로그램에 목록 변경을 알리는 데 사용합니다. 장식용 원에는 `aria-hidden="true"`를 지정합니다.

### 1-2. CSS: 색상과 레이아웃 구성하기

`css/style.css`는 어두운 배경, 노란색 버튼, 둥근 입력창과 목록 항목을 표현합니다.

- **공통 색상:** `:root`에 `--background`, `--yellow`, `--text` 등의 CSS 변수를 선언하고 `var()`로 재사용합니다.
- **박스 크기:** 전체 요소에 `box-sizing: border-box`를 적용해 너비 계산에 테두리와 안쪽 여백을 포함합니다.
- **본문 배치:** `.page-shell`에 그라데이션 배경, 둥근 테두리, `display: grid`, `place-items: center`를 적용해 앱을 중앙에 배치합니다.
- **앱 너비:** `.todo-app`의 `width: min(100%, 560px)`로 최대 너비를 560px로 제한하면서 부모 영역이 좁아지면 함께 줄어들게 합니다.
- **입력 폼:** Flexbox로 입력창과 추가 버튼을 가로로 배치합니다. 입력창의 `flex: 1`은 남은 공간을 채우고, `min-width: 0`은 좁은 공간에서 입력창이 줄어들 수 있게 합니다.
- **목록 배치:** `.todo-item`에 `grid-template-columns: auto minmax(0, 1fr) auto auto`를 적용해 체크박스, 내용, 수정, 삭제를 네 열로 배치합니다.
- **긴 내용:** `.todo-text`의 `overflow-wrap: anywhere`로 긴 문자열도 줄바꿈할 수 있게 합니다.
- **상태 표현:** 수정·삭제 버튼에 마우스를 올리면 노란색으로 바뀌고, 완료된 항목은 회색 글자와 취소선으로 표시됩니다.

완료 표시를 담당하는 스타일은 다음과 같습니다.

```css
.todo-item.is-completed .todo-text {
    color: var(--muted);
    text-decoration: line-through;
}
```

JavaScript가 항목에 `is-completed` 클래스를 추가하면 이 스타일이 적용됩니다. 현재 CSS는 유동 너비를 사용하며, 화면 크기별로 배치를 바꾸는 미디어 쿼리는 포함하지 않습니다.

### 1-3. JavaScript: 데이터와 사용자 동작 연결하기

`js/todo.js`는 `querySelector()`로 폼, 입력창, 목록, 빈 목록 안내를 가져옵니다. 전체 할 일은 `todos` 배열에 저장하고, 각 항목은 다음 형태의 객체로 관리합니다.

```js
{
    id: Date.now(),   // 항목을 구분하기 위한 생성 시각 기반 값
    text: todoText,   // 할 일 내용
    completed: false // 완료 여부
}
```

| 함수 또는 이벤트 | 사용한 방법과 동작 |
| --- | --- |
| `renderTodos()` | 기존 목록을 비우고 `forEach()`로 배열을 순회합니다. `createElement()`와 `append()`로 각 항목과 버튼을 생성하며, 배열 길이에 따라 빈 목록 안내의 `hidden` 값을 변경합니다. |
| 폼의 `submit` 이벤트 | `preventDefault()`로 제출에 따른 새로고침을 막습니다. 입력값에 `trim()`을 적용해 양끝 공백을 제거하고, 공백뿐인 내용은 추가하지 않습니다. |
| `addTodo(todoText)` | 새 객체를 만들고 `push()`로 배열 끝에 추가한 뒤 목록을 다시 그립니다. 제출 처리가 끝나면 입력창을 비우고 다시 포커스합니다. |
| `toggleTodo(todoId)` | `find()`로 대상을 찾아 `completed` 값을 반전합니다. 체크박스의 `change` 이벤트로 호출됩니다. |
| `editTodo(todoId)` | `find()`로 대상을 찾고 `prompt()`에 기존 내용을 보여줍니다. 취소하면 변경하지 않고, 공백 제거 후 내용이 비어 있으면 `alert()`로 안내합니다. 유효한 내용은 `text`에 반영합니다. |
| `deleteTodo(todoId)` | `confirm()`으로 삭제 여부를 확인합니다. 확인하면 `filter()`로 대상 ID를 제외한 배열을 만들어 목록을 갱신합니다. |

`renderTodos()`는 완료 여부에 따라 체크박스의 `checked`와 항목의 `is-completed` 클래스를 설정합니다. 체크박스에는 할 일 내용이 포함된 `aria-label`도 지정합니다. 할 일 내용은 `textContent`로 넣기 때문에 HTML 태그를 입력해도 태그가 실행되지 않고 문자로 표시됩니다.

수정·삭제 버튼의 `click` 이벤트와 체크박스의 `change` 이벤트는 각 요소를 생성할 때 연결합니다. 최초 실행 시 `renderTodos()`를 호출하고, 이후 데이터가 변경될 때마다 목록 전체를 다시 그리는 구조입니다.

```text
사용자 입력 또는 버튼 조작
→ 이벤트 처리
→ todos 배열의 데이터 변경
→ renderTodos() 실행
→ 변경된 목록과 완료 상태를 화면에 표시
```

### 1-4. 향후 개선 제안

아래 내용은 현재 구현에 추가로 적용할 수 있는 개선 사항입니다.

- `.todo-form input`의 `gorder` 오타를 `border`로 수정하면 의도한 입력창 테두리 스타일을 적용할 수 있습니다.
- `.site-brand`에는 `display: flex` 뒤에 `display: grid`가 선언되어 있어 현재 Grid가 적용됩니다. 견본처럼 가로로 배치하려면 중복 선언을 정리할 수 있습니다.
- 한국어 페이지에 맞춰 HTML의 `lang="en"`을 `lang="ko"`로, 문서 제목 `Document`를 페이지 이름으로 변경할 수 있습니다.
- 미디어 쿼리를 추가하면 작은 화면에서 제목 크기와 입력 폼 배치를 조절할 수 있습니다.
- 수정 시에도 100자 검사를 추가하면 생성과 수정의 길이 제한을 통일할 수 있습니다.
- `localStorage` 저장·복원 기능을 추가하면 새로고침한 뒤에도 목록을 유지할 수 있습니다.

## 2. 사용 방법

### 2-1. 페이지 실행하기

1. `index.html`, `css` 폴더, `js` 폴더를 위의 구조대로 같은 폴더에 둡니다.
2. `index.html`을 더블 클릭하거나 웹 브라우저에서 엽니다.
3. 처음 실행하면 빈 목록 안내와 입력창, **추가** 버튼이 표시됩니다.

별도 서버나 설치 명령은 필요하지 않습니다. 스타일이나 기능이 적용되지 않으면 CSS와 JavaScript의 파일 위치 및 HTML의 연결 경로를 확인합니다.

### 2-2. 할 일 생성 및 조회

1. 입력창에 `발표 자료 확인하기`처럼 할 일을 입력합니다.
2. **추가** 버튼을 누르거나 입력창에서 **Enter**를 누릅니다.
3. 입력한 내용이 목록 맨 아래에 표시됩니다. 입력창은 비워지고 다시 입력할 수 있는 상태가 됩니다.

새 항목 입력은 최대 100자로 제한됩니다. 빈 내용이나 공백만 있는 내용은 등록되지 않으며, 내용의 앞뒤 공백은 제거됩니다. 등록한 항목들은 추가한 순서대로 화면에서 확인할 수 있습니다.

### 2-3. 할 일 수정

1. 변경할 항목 오른쪽의 **수정** 버튼을 누릅니다.
2. 기존 내용이 표시된 입력 대화상자에서 내용을 고칩니다.
3. **확인**을 누르면 해당 항목의 내용이 변경됩니다.

**취소**를 누르면 기존 내용이 유지됩니다. 빈 내용이나 공백만 입력하고 확인하면 “빈 내용으로 수정할 수 없습니다.”라는 안내가 표시되고 기존 내용은 유지됩니다. 수정해도 완료 상태는 바뀌지 않습니다. 현재 수정 대화상자에는 100자 제한이 적용되지 않습니다.

### 2-4. 완료 표시와 취소선 해제

1. 완료한 항목 왼쪽의 체크박스를 누릅니다.
2. 해당 내용에 취소선이 생기고 글자색이 회색으로 바뀝니다.
3. 체크박스를 다시 누르면 완료 상태가 해제되고 원래 글자 모양으로 돌아옵니다.

완료한 항목은 목록에 남아 있으며, 수정하거나 삭제할 수 있습니다.

### 2-5. 할 일 삭제

1. 삭제할 항목의 **삭제** 버튼을 누릅니다.
2. “삭제할까요?” 대화상자에서 **확인**을 누릅니다.
3. 해당 항목이 목록에서 제거됩니다.

**취소**를 누르면 항목이 유지됩니다. 마지막 항목까지 삭제하면 빈 목록 안내가 다시 표시됩니다. 삭제한 항목을 복구하는 기능은 없으므로 필요하면 다시 추가합니다.

### 2-6. 데이터 유지 범위

현재 목록은 JavaScript 배열에만 보관됩니다. **페이지를 새로고침하거나 닫았다가 다시 열면 목록이 초기화됩니다.** 브라우저 저장소나 서버에 저장하는 기능은 구현되어 있지 않습니다.

### 2-7. 직접 확인해 볼 사용 순서

1. 할 일을 두 개 추가하고 입력한 순서대로 보이는지 확인합니다.
2. 첫 번째 항목을 수정한 뒤 변경된 내용을 확인합니다.
3. 두 번째 항목의 체크박스를 선택하고 취소선이 생기는지 확인합니다.
4. 체크를 해제하고 취소선이 사라지는지 확인합니다.
5. 수정 대화상자에서 취소하거나 빈 내용을 입력해 기존 내용이 유지되는지 확인합니다.
6. 삭제 대화상자에서 취소한 뒤 항목이 남는지 확인하고, 다시 삭제하여 확인을 누릅니다.
7. 모든 항목을 삭제한 뒤 빈 목록 안내가 표시되는지 확인합니다.
