# 내 업보들 — Todo 앱

Lovable 참고 화면을 바탕으로 만든 개인 Todo 앱입니다. HTML로 입력 폼과 세 칸 보드를
구성하고, Tailwind CSS Play CDN과 CSS로 화면을 꾸미며, JavaScript로 동작을 처리합니다.

## 실행

저장소의 `jungeun/index.html`을 브라우저로 열거나 VS Code Live Server로 실행합니다.
앱 실행에 패키지 설치나 백엔드 서버는 필요하지 않습니다. Tailwind Play CDN을
불러오려면 인터넷 연결이 필요합니다.

## 파일 구조

```text
jungeun/
├── index.html             # 앱 진입 화면
├── css/style.css          # 화면 스타일
├── js/todo.js             # Todo 동작과 브라우저 저장
└── README.md              # 실행과 기능 안내
```

## 현재 기능과 동작 확인

1. 입력 후 **업보 추가** 또는 Enter로 등록하면 Backlog에 나타납니다.
2. 하단 검색창에 단어를 입력하고 **조회** 또는 Enter를 누르면 제목에 해당 단어가
   포함된 할 일만 표시됩니다. 영문 대소문자는 구분하지 않습니다. 검색어를 지우면
   전체 목록이 표시되며, 검색은 저장된 원본 목록을 변경하지 않습니다.
3. **말 바꾸기**로 제목을 수정하고 **×**로 삭제합니다. 빈 제목은 등록·수정할 수 없습니다.
4. **증거 인멸**은 검색 결과와 관계없이 저장된 모든 완료 항목을 삭제합니다.
   완료 항목이 없으면 버튼이 비활성화됩니다.
5. 칸의 숫자는 검색 결과의 개수이며, 하단 남은 일은 전체 미완료 항목 수입니다.
   날짜는 한국 시간 기준으로 표시됩니다.

Backlog / In Progress / Done은 저장된 `status`에 따라 표시됩니다. 새 항목은 Backlog에
추가되며, 현재 화면에는 Status 메뉴·드래그·완료 체크 등 상태를 변경하는 UI가 없습니다.
따라서 현재 앱만으로 항목을 In Progress 또는 Done으로 옮길 수 없습니다. 발표자료나
별도 영상의 상태 이동 구상 시연은 실제 구현 기능을 뜻하지 않습니다.

## 데이터 저장

할 일은 현재 브라우저의 `localStorage`에 `todos` 키로 저장됩니다. 새로고침 후에도
같은 브라우저·접속 주소에서 목록을 불러옵니다. `todos`가 없으면 이전
`jungeun-todos-v1` 데이터를 읽으며, 이전 형식의 완료 항목도 표시할 수 있습니다.

서버 전송이나 계정 간 동기화 기능은 없습니다. 다른 브라우저·접속 주소에서는
별도 저장소를 사용하며, 브라우저 저장 데이터를 삭제하면 목록도 사라집니다.
